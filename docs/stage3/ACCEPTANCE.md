## 本轮修复的具体问题

1. 顶层任务新增/编辑原先把保存和查询放在同一失败路径，保存成功但查询失败时可能重复提交。现在写成功即返回已保存任务，查询错误由列表展示并提供重试。
2. 项目旧 GET 响应可能覆盖刚创建、编辑或删除的项目。新增断言先复现该问题，再用请求序号及写成功后的失效处理修复；删除当前项目同步清空选择。
3. 日期选择器按字符串解析 `0004-02-29` 会映射为 1904 年。改为本地 Date 与字符串之间的明确转换，使用 setFullYear 保留低年份，选择器限制 0001～9999；浏览器已验证 0004 年原样回填/保存。
4. Mock 拒绝非法日期、非对象 JSON 更新体、不可变字段修改、非法分页/状态/overdue 参数；完整候选快照校验失败时零写入或回滚有效状态。
